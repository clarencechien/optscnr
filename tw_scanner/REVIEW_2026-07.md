## 一、tw_scanner（台股籌碼天氣台）：**留任**

- **capitulation 警報與基線可分離**（2026-07 回測，6 個事件簇）：
  20 日中位數 +5.75% vs 無條件基線 +2.19%；60 日中位數 +9.80% vs +4.94%、
  命中率 83%。n 小不主張顯著性，但方向一致且與設計目的（DCA 加碼窗口）吻合。
- **自我審判機制在運作**：overheat 警報 2026-06-11 已處決（頂部是過程不是事件，
  抓不到），判決書留在 config。會殺自己儀器的系統，其留下來的儀器才可信。
- **活體測試進行中**：2026-07-30 鋒面 CAPITULATION、投降警報響起。
  這次警報的 T+20/T+60 結果（~8 月底/10 月底可判）是下一個天然檢驗點。

### 改進項（依優先序）

1. **預報員評分（v3 候選，維持原規劃）**：regime → P(20日報酬<0) 機率映射 +
   季度 Brier 校準曲線。state.json 已一交易日一行，地基是好的。
2. **7/30 警報結果回填**：8 月底把本次警報的 T+20 記入審判記錄（不管結果如何——
   響錯也是樣本）。
3. **不動的**：四特徵、252 日分位參照系、三日遲滯、五態鋒面。已回測驗證的部分
   不因單次事件調整。

## 二、delta_radar（2308 馬賽克雷達）：**不退役，但改讀法＋設退役判準**

### 資料說了什麼（M7 回填 63 筆，2026-07-30 止）

市場基準：T+20 期間 0050 +0.33%、2308 絕對報酬 **-13.81%**。

| cohort | n | T+20 超額%（2308−0050） |
|---|---|---|
| baseline (all) | 63 | -14.13 |
| M1=GREEN | 33 | -15.10 |
| M2=GREEN | 7 | **-18.66** |
| M2=YELLOW | 22 | -12.33 |
| M5=RED | 17 | -17.86 |
| M5=YELLOW | 20 | -8.70 |

三個誠實的結論：

1. **作為「交易訊號」它零價值。** 前提模組全綠的期間，2308 跑輸 0050 達 15 個百分點。
   誰拿色燈當進場依據誰賠錢——但它的設計文件從第一天就寫明
   「shadow-mode instrument，不是交易訊號」，這不是它的罪。
2. **作為「論點監控儀器」它照設計運作，且此刻正產出它存在理由的那個情境**：
   前提全綠（營收 +55%、FCF/淨利 1.32、海關 +50%）＋股價 20 日跌 14% ＝
   **跌的是估值，不是基本面**。這對「持 2308 / 信 GS 4500 劇本」的人是有價值的資訊
   （該慌的訊號是前提破，不是價格跌）。問題在：這個「背離」目前要人腦自己從
   報告和股價兩處拼出來——儀器沒把它說出口。
3. **有一個模組出現反向跡象**：M2=GREEN cohort（-18.66%）比 M2=YELLOW（-12.33%）
   更差。n=7 太小不能定罪，但這是「gate 方向可能接反」的初步證據，列入觀察。
   M5 則有正向跡象：RED（-17.86）確實比 YELLOW（-8.70）差，敘事桶的方向是對的。

### 改進項（依優先序）

1. **加「前提-價格背離」旗標**（把儀器的存在理由說出口）：
   總判定為 GREEN/YELLOW 且 2308 同期 20 日絕對報酬 < -10% 時，報告頂部加一行
   `🔀 背離：前提健在、價格重挫 ——跌的是估值不是基本面（或市場知道儀器不知道的事）`。
   反向（前提轉紅＋價格沒跌）同樣標出。M7 已在算遠期報酬，資料現成。
2. **訂退役判準（寫死，防止將來捨不得）**：任一模組在該模組 cohort n≥30 後，
   其 GREEN cohort 的 T+20 超額報酬仍劣於自己的 YELLOW/RED cohort → 該模組處決
   （狀態改 ⚪ RETIRED，判決書進 config，同 tw_scanner overheat 前例）。
   **整支雷達的退役判準**：2026-10 底（Q3 財報後）覆核，若屆時（a）背離旗標從未
   提供過一次可行動的資訊、且（b）沒有任何模組通過「GREEN cohort 優於自己
   RED/YELLOW cohort」的最低檢驗 → 整支封存（保留 state.json 供歷史回測，
   workflows 停用）。
3. **維護成本已降**：2026-07-31 起與 tw_scanner 共用資料夾/requirements/README
   管線，邊際成本趨近於零——這不是留任的理由，但讓「再觀察一季」的成本可以接受。

### 不做的

- 不因 hit-rate 表調任何 gate 閾值（n 小、單一下跌行情，只讀方向不讀精度——
  表尾自己就這麼寫）。
- 不把 delta_radar 改造成擇時工具。它要嘛是論點監控，要嘛封存，沒有中間形態。

### 樣本 n≥30 之後可加的方向（2026-09-12 記；下次覆核再看，之前不動）

起因：使用者問「紅燈是論點破壞、要考慮持有風險？」與「綠燈但股價沒漲，是不是先行指標？」。
當日回答（記下來免得下次重講）：
- 紅燈＝**那一條前提正被資料反駁**，管「要不要加碼／賭場開不開新局」，不管「要不要出清」。
  總判定要 2 顆模組 RED 才 RED；M3／M9 是觀察模組不進總判定；M5／M8 是敘事模組，噪音大。
- 2330 首跑 M5 RED 是 placeholder 門檻（16 則 vs red 15）造成，5 次 run 後 z-score 接手會自己退。
- 2308 M6 RED（雙鴻領先 36pp，`peer_lead_risk`）是真的，但要看雙鴻基期小；圖像是「成長還在、加速結束、散熱有人跑更快」。
- 「綠燈價格沒漲」是**假說**：模組本身落後（月營收／季報／海關），月營收全市場都看得到，
  而且成長股多數時候都綠、20 日走平本來就常見，要比條件機率不是找例子。

**等資料夠了才准開的實驗**（每格 n≥30、該模組狀態翻轉 ≥3 次；delta 10/31、tsmc 12/31 覆核時看）：
1. **燈色 × 價格狀態交叉表**：總判定 {GREEN, YELLOW, RED} × 近 20 日報酬 {跌 ≤ −10%, 平, 漲} → T+20 對 0050 超額
   （2330 另看對 SMH）。假說要成立得同時滿足：「綠且平」優於「綠且漲」、且優於無條件平均。
   不成立 → 背離旗標降為純描述，報告不再暗示方向。資料 `m7_outcome_backfill` 已經在記，只差切表。
2. **硬資料模組 vs 敘事模組分開算退役**：M1/M2/M4 的 RED（連 2 次 run）與 M5/M8 的 RED 各自對 T+20 的分離度。
   若敘事模組分不出來 → 退出總判定、降觀察；若硬資料也分不出來 → 整支雷達處決候選。
3. **觀察模組轉正的條件**：M3（ADR 溢價 1 年分位／泰國影子）與 M9（PER 3 年分位）的低分位是否預測 T+20。
   有分離才准進總判定；沒有就永遠是觀察，不要因為「看起來有道理」升格。
4. **讀法規則候選（尚未寫進程式，先當人工紀律）**：硬資料模組 RED 連續 2 次 run、或總判定 RED → 賭場該檔停止新增；
   DCA 0050 規則不受任何燈色影響。要不要寫進 casino_tracker，等 1 有結論再說。
5. tsmc：M5 z-score 接手後確認 RED 退掉；`--dump-accounts` 找合約負債科目；placeholder 門檻對照真資料校準（不是「調」，是「首次設定」）。

判準先寫死：以上任一項在 n 不足時「一律累積中」，不看方向、不寫結論；寫結論的人要在本檔留下 n 與翻轉數。
