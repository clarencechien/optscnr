# tw_scanner — 台股籌碼天氣台

---

# 上篇：給一般讀者

> 這是一份「股市天氣報告」。它告訴你今天市場冷不冷、天氣型態有沒有
> 改變、有沒有罕見的暴風——它**不會**告訴你明天會漲還是會跌，
> 也沒有任何工具做得到這件事。

## 這台機器每天晚上做什麼

台灣股市每天收盤後，交易所會公布幾個「大家今天做了什麼」的官方數字：
外國投資人買了還是賣了多少、一般散戶借錢買股票（融資）是增加還是減少、
散戶在期貨市場押多還是押空。這台機器每晚自動把這些數字抓下來，
然後做一件很簡單但很多人不做的事——

**不問「這個數字大不大」，只問「跟過去一年比，今天排第幾名」。**

例如「外資賣 300 億」聽起來很可怕，但如果過去一年有四十天賣得比這
更多，那它其實只是普通的冷天；反過來，一個看似平常的數字若是一年來
最極端的，那才值得注意。所有判讀都用「百分位」呈現：第 50 是普通日子，
第 5 以下或第 95 以上才是極端。

## 報告怎麼讀（每天一分鐘）

報告分三層，由淺入深：

1. **溫度計** — 四個指標今天各排第幾百分位。看一眼，知道冷暖。
2. **鋒面** — 把溫度綜合成五種天氣型態：🥶 投降 / 🌧️ 轉冷 / ⛅ 普通 /
   ☀️ 偏熱 / 🔥 過熱。型態要**連續三天**站穩才會改變，所以它不會被
   單日的大漲大跌嚇到亂叫。沒變的日子，它什麼話都不說。
3. **暴風警報** — 一年只響幾次。當「外資極端賣壓＋融資斷頭潮＋散戶
   棄守」三件事在同一天發生，歷史上那種日子往往是恐慌的最高點。
   回顧 2019 年以來，它響過的日子包括 2020 年 3 月疫情股災的最低點
   當天、2024 年 8 月 5 日台股史上最大單日跌幅——之後一到三個月，
   市場平均表現明顯好於平常。

## 你可以拿它做什麼

它是為一種人設計的：**定期定額買大盤指數的人**。對這種人，它的
用法只有一條——平常照你原本的節奏買，**警報響起的那幾天，是歷史上
「加碼比平常划算」的日子**。因為對定期定額者來說，這個訊號就算錯了，
代價只是「本來就要買的錢早買了幾天」；但如果它對了，你買在了多年
難得一見的低點。

## 它不能做什麼（很重要）

- **它不能預測明天。** 這些數據是收盤後才公布的，而且市場情緒一冷
  可以冷好幾週——知道今天很冷，不代表明天會更冷或回暖。
- **它不會叫你賣股票。** 我們測試過「過熱警報」（想抓頭部），結果
  發現抓不到——市場的底部是恐慌擠在一天爆發，頭部卻是慢慢形成的，
  所以這台機器天生只會抓底部恐慌，不會抓頂部。🔥 過熱只是溫度描述。
- **它不是投資建議。** 它是一支溫度計。看了之後做什麼決定，是你的事。
- **它有可能錯。** 警報的歷史樣本只有六次，而且這六次都發生在大致
  向上的年代。如果未來遇到連跌好幾年的大空頭，「恐慌日之後會反彈」
  這條歷史規律可能失效。機器每個月會自動重新檢驗自己，但無法保證。

# 下篇：給維護者（需要 context 才看得懂）

## 規格淵源

2026-06-11 規格會議結論：放棄 D+1（盤後揭露＋訊號自相關以週計＝
日線無 alpha 路徑，與 Gemma 21B D+1 評估同構），鎖定 DCA 冷暖。
前身為「三數字配罐頭台詞」報告器——數據層經三方交叉驗證無罪
（spot -357.79 億、TX -63,168 口與 TAIFEX/FinMind 全對齊），
解釋層 Good data In, Drama Out，故重寫解釋層、保留數據源。

## 架構

```
四特徵 ──252日滾動分位數──► score ∈ [-1,1] ──3日遲滯──► 五態鋒面
   │                                                       │
   └──尾部共現 (≤5pct × ≤5pct × 散戶翻空)──► capitulation 警報
                                                  │
                                            --backtest 審判
```

特徵與口徑：
- `f_spot_20d`：FinMind `TaiwanStockTotalInstitutionalInvestors`，
  釘 `^Foreign_Investor$`（排除 total 行與 Foreign_Dealer_Self，
  對齊官方外資及陸資口徑），20 日滾動和。
- `tx_delta`：`TaiwanFuturesInstitutionalInvestors` TX，釘 `^外資$`。
  **只讀 Δ 不讀水位**——2026/5 實證：淨空單水位「極端」橫跨五週
  創新高行情（5/8 破紀錄 54,530 → 6/2 再破 67,018 同日指數新高），
  水位無擇時資訊，避險帳冊性質。媒體口徑常含小台折算，差數千口
  屬正常，本機只依賴序列內部一致性。
- `retail_mtx`：MTX 三法人淨倉反向，白名單 `自營商|投信|外資`
  防 FinMind 日後加 total 行。
- `margin_chg`：釘 `^MarginPurchaseMoney$`——`融資|Margin` 舊 regex
  會同時吃到金額與**張數**行（與 delta_radar M2 同款跨科目加總 bug）。
  分位數判讀使單位（元/仟元）成為非問題。

所有 `_pinned` 釘選依據 2026-06-11 `--dump-schema` 實彈對帳，記錄
在 config。schema 漂移時 resolver 報錯不猜測。

## 審判記錄（Tier 3）

- **capitulation：VALIDATED**。2019–2026 六簇：2020-03-09/19、
  2022-03-08、2024-04-22、2024-07-19、2024-08-05。20 日中位數
  +5.75% vs 基線 +2.22%；60 日 +9.80% vs +5.04%、命中 83%。
  n=6 不主張顯著性；轉正依據是 DCA 報酬不對稱。非 DCA 用途
  （槓桿擇時）不適用。
- **overheat：RETIRED 2026-06-11**。寬鬆閾值（90/85/70）更審後
  七年僅兩簇（2021-06-11、2026-06-01），唯一可測事件 20 日 +3.49%
  方向錯誤。結構性死因：底部是事件、頂部是過程。Tier 2 OVERHEAT
  鋒面保留為溫度描述。2026-06-01 單發神準（崩盤前七個交易日）
  記入軼事不記入儀器——用結果反推轉正即是這台機器存在的反面教材。
  判決書全文在 config `_verdict`。

## 已知限制（量化表述）

1. 分位數參照系 252 日：結構性變遷（稅制、准入規則）會使分位失真，
   無自我察覺機制。
2. 回測時代偏誤：樣本全落在 2020 起的大多頭，長空頭下的連環投降
   情境 out-of-sample。每月一號排程重審，分離度塌即更新判決。
3. 鋒面遲滯三日 = 轉折確認恆晚三天，設計取捨非缺陷。
4. 融資 21:00 揭露：日間手動跑為 3/4 特徵（簡報明示），完整讀數
   以 21:45 排程為準。
5. state.json 防重閘：同 date 重跑採 replace 非 append，序列保持
   一交易日一行——這是日後 Brier 評分的地基。預報員評分尚未實作
   （v3 候選）：regime → P(20日報酬<0) 映射 + 季度校準曲線。

## 操作

```bash
python tw_scanner.py                   # 每日簡報（cache 增量）
python tw_scanner.py --backfill        # 重建 2019 起歷史
python tw_scanner.py --backtest        # 重審警報 vs 基線
python tw_scanner.py --dump-schema     # FinMind 欄位對帳
python tw_scanner.py --selftest        # 零網路管線驗證（OU 合成市場）
```

Env `FINMIND_TOKEN` 選填。排程 `.github/workflows/tw_scanner.yml`：
平日 13:45 UTC（21:45 台北，融資公布後）簡報、每月一號 backtest。
cache CSV 進版控：回測可重現＋省 FinMind 額度。

## 設計憲法（radar 家族共同紀律）

閾值全外部化；schema 候選名單＋對帳釘死＋`_pinned` 記錄；模組失敗
降級為缺值、永不無聲吞錯（含 workflow 的顯式 `git add` 存在性檢查）；
測量與敘事分家、敘事僅由狀態轉移產生；警報必須通過回測審判，
無法與基線分離者處決，屍體留 config 當紀念。
