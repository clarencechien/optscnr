# 妖股獵殺報表 — 使用手冊（新手友善版）

> 這份手冊有兩個用途：
> 1. **給你看**：看懂每天的 `README.md`（妖股獵殺報表）在說什麼。
> 2. **給 AI 看**：搭配下方的「System Prompt」，貼到 ChatGPT / Gemini / Claude，把報表丟進去，AI 會用白話幫你摘要、標風險、列出你該自己想清楚的問題。

---

## ⚠️ 先讀這段：這個工具是什麼，不是什麼

**這是什麼**：一個每天自動掃描「便宜、有人氣、剛開始有資金流入」的選擇權的雷達。它幫你**過濾雜訊**，把幾千個標的縮小到幾個「值得看一眼」的。

**這不是什麼**：
- ❌ 不是「保證會漲」的名單。雷達掃到 ≠ 該買。
- ❌ 不是「AI 幫你選股、你照買就好」。最終決定永遠是你。
- ❌ 不適合下重注。這些是**高風險投機標的**（所以叫「妖股」），會大漲也會歸零。

**鐵則（寫在筆記第一頁）**：
1. **只用閒錢**——這筆錢全部賠光，不影響你的生活。
2. **單一標的不超過總資金的 0.5%–1%**——這樣就算歸零也只是小傷。
3. **賺到翻倍（+100%）先賣一半**——剩下的當「免費的籌碼」續抱。這叫 free ride，是這套玩法能長期活下來的關鍵。
4. **看不懂的，就不要碰**——不懂沒關係，跳過它，世界上機會很多。

## 一、報表怎麼看：Score（分數）

每個標的會有一個 **Score（0–5 分）**，代表「這個機會的含金量與急迫性」。分數越高，代表越多好訊號同時出現。

| 分數 | 白話意思 | 該做什麼 |
|---|---|---|
| **1–2 分** | 便宜、有人埋伏，但還沒動靜 | 不急。想要的話掛個低價單慢慢等 |
| **3–5 分** | 便宜 + 人多 + **資金正在湧入**（剛點火） | 比較有戲，但**越急的訊號越要冷靜**，別追高 |

**分數怎麼來的**（不用背，知道就好）：
- 便宜又有人氣 → +1 分
- 超多人押同一個 → +1 分
- **成交量突然爆增（主力進場）→ +3 分**（最重要的訊號）

## 二、報表的 Action（動作標籤）怎麼讀

報表每個標的有一個 Action 標籤。**新手版解讀**（拿掉術語、加上保護）：

### 🚀 STRONG_BUY（強訊號）
- **意思**：便宜 + 人多 + 資金剛湧入，三個好訊號同時出現。
- **新手注意**：原始系統說「追價、速度是關鍵」——**但新手不要這樣做**。強訊號代表它已經在漲，追高風險大。如果要參與，**先用最小部位（0.2%）試水溫**，不要一次重壓。
- **更安全的做法**：把它加進觀察清單，觀察 1–2 天它站不站得穩，再決定。

### 👀 BUY_WATCH（觀察）
- **意思**：有資金流入的跡象，但訊號還不夠完整。
- **動作**：**先別買**，加進觀察清單，設個價格提醒。看它接下來幾天怎麼走。

### 🚬 HOLD（埋伏）
- **意思**：便宜、很多人押，但目前沒動靜（在等發動）。
- **動作**：不急。如果有興趣，掛一個「比現價低一點的單」慢慢等別人賣給你。成交了就放著，沒成交也沒損失。

### ⚠️ SELL_ALERT（時間警示）
- **意思**：這個選擇權快到期了（< 45 天）。選擇權越接近到期，時間價值流失越快，會吃掉你的本金。
- **動作**：**如果你持有它 → 認真考慮出場**，不管賺賠。把剩下的錢收回來，留給下一個機會。

---

## 三、新手最常見的三個情境

### 情境 A：看到一個「便宜、很多人押、但沒動靜」的（HOLD）
- **心態**：這是「埋伏等發動」，不是今天就會漲。
- **動作**：用很小的錢（總資金 0.2%），掛一個比現價低一點的單。買到就放著，設定「翻倍賣一半」。**買不到也完全沒差**。

### 情境 B：早上打開發現某個變成 🚀 STRONG_BUY（很少見）
- **心態**：別被腎上腺素帶著走。越興奮的時候越容易買在最高點。
- **新手動作**：**先深呼吸**。問自己三個問題（見下方檢查清單）。如果都過關，用最小部位（0.2%–0.5%）參與，**絕不 all in**。

### 情境 C：你持有的東西，人氣連續幾天下滑
- **意思**：派對可能結束了，資金在撤。
- **動作**：考慮跟著出場。就算沒虧多少也先收回來——支撐它上漲的力量消失了。

---

## 四、進場前，逼自己回答這三個問題

**任何標的，買之前先過這三關。任何一關答不出來 → 不要買。**

1. **這筆錢賠光，我的生活會受影響嗎？**
   - 會 → 不要買。只能用閒錢。

2. **我懂這檔在賭什麼嗎？**（這公司在做什麼、為什麼可能漲）
   - 不懂 → 不要買。看不懂的不碰。

3. **這檔如果明天歸零，我能接受嗎？**
   - 不能 → 部位太大了，砍到你能接受的大小，或不要買。

---

## 五、給 AI 分析時，你會得到什麼

把今天的 `README.md` 貼給設定好 System Prompt 的 AI，它會回你：

1. **白話摘要**：今天報表整體在說什麼（市場熱不熱、有沒有強訊號）。
2. **重點標的（最多 3–5 個）**：挑出分數高/訊號強的，**每個都標風險等級**，並解釋它在賭什麼。
3. **風險提醒**：哪些看起來誘人但其實很危險、哪些是雜訊。
4. **該自己想的問題**：針對今天的標的，AI 會把上面那三個問題具體化，逼你自己做決定。
5. **AI 不會做的事**：不會說「保證賺」、不會叫你 all in、不會幫你做最終買賣決定。

---

## 六、長期紀律（湯姆熊永動機）

把投機帳戶當成「遊戲幣」，跟你的核心資產分開：

1. **設一個上限**（例如總資產的 1%）當作投機本金。
2. **定期結算**（例如每年聖誕節全部結清）：
   - 賺超過上限 → 把多賺的轉走（犒賞自己或存起來）。
   - 低於上限 → 從核心資產補回到上限。
3. **重設**：用新的額度去找下一輪機會。

**核心精神**：**贏了守得住（會提款），輸了賠得起（只用閒錢）。** 不要讓投機帳戶無限膨脹變成你資產的一大塊——那一天市場一個轉身就會重傷你。

---

## 七、系統維護（偶爾才需要）

- **掃不到便宜標的**：市場大漲時所有選擇權都變貴，屬正常。可調高 `main.py` 的 `CHEAP_PRICE` 門檻。
- **想掃別的股票**：改 `main.py` 的 `TARGET_TICKERS`。
- **GitHub 沒更新**：去 repo 的 Actions 分頁看是不是失敗（紅燈）。403 錯誤通常是被擋，休息幾天或手動 re-run。

# 📋 System Prompt（複製這段，貼到 ChatGPT / Gemini / Claude）

> **使用方式**：開一個新對話，把下面整段（從「你是」到結尾）貼進去當第一則訊息（或設成 Custom Instructions / System Prompt / Gem 指令）。之後每天只要把 `README.md` 報表內容貼進來，它就會分析。三個平台都通用。

```
你是一個「妖股報表分析助手」。使用者是投資新手，沒有太多股市或財經知識。
他會貼給你一份每日「妖股獵殺報表」（一個掃描高風險選擇權的自動化系統產出的 markdown），
你的工作是用白話幫他看懂、標出風險，並逼他自己做決定——但絕對不替他做最終買賣決定。

【背景知識：報表怎麼讀】
- Score（0–5 分）：機會的含金量與急迫性。1–2 分=有埋伏沒動靜；3–5 分=資金正在湧入。
- Action 標籤：
  - 🚀 STRONG_BUY = 便宜+人多+資金剛湧入（但已在漲，追高有風險）
  - 👀 BUY_WATCH = 有流入跡象但訊號不完整（先觀察別急買）
  - 🚬 HOLD = 便宜、多人押、沒動靜（埋伏等發動）
  - ⚠️ SELL_ALERT = 快到期（< 45 天），時間價值快速流失，持有者該考慮出場
- 這些全是高風險投機標的（所以叫妖股），會大漲也會歸零。

【你每次回覆的固定格式】
1. 📊 今日總覽：用 2–3 句白話說今天報表整體在講什麼（市場熱不熱、有沒有強訊號、整體該積極還是觀望）。
2. 🎯 重點標的（最多 3–5 個）：從報表挑出分數高或訊號強的，每個用這個格式：
   - 標的代號 + Action 標籤
   - 一句白話：它在賭什麼（這公司/這個押注是什麼，用國中生聽得懂的話）
   - 風險等級：🟢較低 / 🟡中等 / 🔴高（妖股大多是 🟡🔴，誠實標）
   - 為什麼要小心：具體說這檔的風險點
3. 🗑️ 可以略過的：哪些看起來有訊號但其實是雜訊、或風險高到不值得新手碰。
4. ❓ 買之前先問自己（針對今天標的具體化這三題）：
   - 這筆錢賠光會影響生活嗎？（只能用閒錢）
   - 我懂這檔在賭什麼嗎？（不懂就不碰）
   - 它明天歸零我能接受嗎？（不能就是部位太大）
5. ⛔ 鐵則提醒（每次都附）：單一標的不超過總資金 0.5%–1%；賺翻倍先賣一半；看不懂的不要碰。

【你必須遵守的紅線】
- 絕不說「保證賺」「穩賺」「一定漲」「all in」「重壓」「梭哈」這類字眼。
- 絕不替使用者做最終買賣決定。你提供資訊和風險，決定權在他。
- 不確定的資料不要瞎編。報表沒寫的數據，就說「報表未提供」。
- 如果使用者問「我該買哪個」，回答要導向「這幾個值得你研究，但要先過上面三個問題，最終由你決定」，而不是直接點名「買這個」。
- 如果某個標的風險明顯過高（快到期、極度投機），就算分數高也要明確警告新手別碰。
- 使用者情緒激動想追高時（例如說「這個一定要買」），提醒他冷靜，越興奮越容易買在高點。
- 全程用繁體中文、白話、避免術語。必須用術語時（如 OI、IV、Theta）立刻用一句話解釋。

記住：你的價值不是幫他選到飆股，是讓一個新手「看懂報表、控制風險、自己做出不會後悔的決定」。
寧可讓他少賺，也不要讓他因為你的話而重傷。
```

## 💡 進階：給「會用 agents.md 的工具」（選讀）

如果你之後改用支援 `agents.md` 的 agent 框架（如 Claude Code、或自架 agent），可以把上面 System Prompt 那段放進 `agents.md`，並加上工具權限說明，例如：

```markdown
# Agent: 妖股報表分析助手

## 角色
（貼上方 System Prompt 全文）

## 可用工具
- read_file: 讀取 data/ 下的報表與雷達 JSON
- web_search: 查證標的的最新消息（僅供風險評估，不可作為買進依據）

## 禁止
- 不可直接下單或連接券商
- 不可替使用者做最終買賣決定
```

但對「web UI 手動貼報表」的用法，上面那段 System Prompt 就夠了，不需要 agents.md。
