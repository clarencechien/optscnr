# 出場決策清單（跳車手冊）

> 這份是給「已經買進、還沒出場」的部位用的。
> Scanner 負責找進場機會；這份負責回答「我手上這個，什麼時候該走」。
> **核心精神：出場規則要在「進場當下、頭腦冷靜時」就定好，不要等到帳面綠了或紅了才臨場決定——那時候情緒會幫你做錯決定。**

---

## 〇、進場那一刻，先寫下三個數字

買進任何一個選擇權部位的當下（趁還沒有情緒），立刻記下這三個數字。寫在筆記、便條、手機備忘錄都行：

```
標的：__________   進場日：______   到期日：______
1. 進場成本（每口權利金）：$______
2. 認賠線（跌到這裡無條件走）：$______   ← 見第一節
3. 這個部位在賭什麼（一句話）：__________________
   （例：賭 PATH 財報後 IV 殺完、籌碼洗乾淨的波段反彈）
```

> 第 3 點最重要。**你買它一定有個理由（論點）。出場的第一準則不是看價格，是看「這個論點還在不在」。**

---

## 一、A 機制：小賺/小賠跳車（還沒翻倍時）

這是你最缺、也最痛的狀態：**綠的、但沒到 +100%、還沒 free ride。**

### 跳車訊號（任一成立就認真考慮走，不用全中）

**1. 論點破壞 —— 最優先，無條件走**
- 你進場的理由（第〇節第 3 點）消失了或被推翻了。
- 例：你賭「財報後反彈」，結果反彈兩天就熄火、量縮、OI 不再增加 → 論點死了，**就算還是綠的也走**。
- **這條凌駕一切**。論點沒了，賺賠都該走，因為你已經沒有續抱的理由。

**2. 認賠線 —— 跌破無條件走（不要凹）**
- 進場前就設好：選擇權權利金跌到進場成本的 **−40% ～ −50%**，無條件砍。
- 為什麼是 40–50% 不是更小：選擇權波動本來就大，停損設太緊會被正常震盪掃出場。但跌超過一半，通常代表你看錯了。
- **關鍵：這條在進場時就設 GTC 賣單，不要盤中用「感覺」決定。** 凹單是選擇權殺手。

**3. 小賺保護 —— 由賺轉回吐時**
- 如果曾經來到 +30% 以上，然後回吐到只剩 +10% 以內 → 考慮收掉。
- 意思是：它衝過一波但沒站穩，動能在消退。小賺收手不丟臉。
- **不適用於剛進場就小綠的狀態**——那還沒表態，給它時間。

### 不該跳車的時候（忍住）
- 剛進場 1–2 天、小綠小紅來回 → **這是正常波動，不是訊號**。給論點時間發酵。
- 只是因為「看它綠了手癢想落袋」→ 沒有訊號的獲利了結，是在扼殺還沒長大的部位。

---

## 二、B 機制：free ride 後何時全收（已翻倍賣一半之後）

恭喜，到這步代表你做對了。剩下的是「免費籌碼」，但**免費不等於無限期持有**。

### 全收訊號（任一成立就把剩下的半倉收掉）

**1. 動能轉折 —— 主力在撤**
- OI（未平倉量）連續 2–3 天明顯下降（例：從 5 萬掉到 3 萬）→ 推它上漲的資金在離場。
- 成交量萎縮 + 價格不再創新高 → 派對結束。
- **Gamma 磁鐵消失了，沒有續抱的理由。**

**2. 時間防線 —— 不要等到最後 21 天**
- 你原本的 SELL_ALERT 是 45 天。但對「已經 free ride、賺夠了」的部位，**標準要更嚴：到期前 21 天就全收。**
- 為什麼：最後 21 天是 Theta（時間價值流失）最兇的階段，每天都在啃你的帳面。免費籌碼也是利潤，沒必要拿利潤去餵 Theta。
- **「賺到頭了就現在收」勝過「等它表演到最後一刻」。** 你已經 free ride 賺到該賺的，剩下是在賭尾段，賭輸了把已實現的爽感變成「早知道就收」。

**3. 目標達標 —— 二次翻倍**
- 剩下的半倉又從你的成本基礎漲了一大段（例如再 +100%）→ 可以再賣一半，或直接全收。
- 沒有「該抱多久」的標準答案，但**「漲多了就分批收」永遠不會錯。**

### free ride 的心法
- 賣一半之後，剩下的「成本是零」——這讓你心理上能抱得住、不會因為小回吐就慌。
- 但「抱得住」≠「該一直抱」。**動能訊號或時間防線一到，就收。** 免費籌碼的任務是「博一個大的」，博完就落袋。

## 三、把你的 PATH 套進去（活的範例）

你現在的狀態：**綠的、沒翻倍、剛進場、論點是「財報後 IV 殺完的波段反彈」。**

對照上面，你現在屬於 **A 機制**，而且：

1. **論點還在嗎？** → 7/17 $15C 有 +954 口真實建倉，代表事件後重新建倉的波段可能還在發酵。**論點目前活著 → 沒有走的理由。**
2. **認賠線設了嗎？** → 如果你進場時沒設，**現在補設**：算出你成本的 −40~50% 是多少，掛 GTC 賣單。這是你現在最該做的動作。
3. **要不要因為綠了就跑？** → **不要**。你還沒翻倍、論點還在、剛進場。這時候跑是「沒有訊號的獲利了結」，扼殺還沒長大的部位。

**結論：你現在不該跳車，但該補一個認賠線。** 等它要嘛翻倍（進入 B 機制 free ride），要嘛論點死掉（A 機制走人），要嘛跌破認賠線（無條件走）。**在那之前，按兵不動就是正確答案。**

## 四、一頁速查表

| 你的部位狀態 | 看什麼 | 動作 |
|---|---|---|
| 剛進場、小綠小紅 | 論點還在嗎 | 在 → 抱著；設好認賠線 |
| 沒翻倍、論點死了 | 論點 | 無條件走（賺賠都走） |
| 沒翻倍、跌破 −40~50% | 認賠線 | 無條件砍（別凹） |
| 沒翻倍、曾 +30% 後回吐到 +10% | 動能 | 考慮小賺收手 |

| free ride 中、又 +100% | 目標 | 再賣一半或全收 |

## 五、三條鐵則（貼在螢幕上）

1. **出場規則進場時就定好。** 帳面綠/紅的時候，情緒會幫你做錯決定。
2. **論點 > 價格。** 第一個該問的永遠是「我當初買它的理由還在嗎」，不是「現在賺賠多少」。
3. **賺到頭了就收，不要餵 Theta。** free ride 後到期前 21 天全清，別賭尾段把已實現利潤變後悔。
